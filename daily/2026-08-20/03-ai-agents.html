2026年8月20日の AI Agents は、水曜の「逃げた評価が訓練を止め、4体が5年を2週間にし、Elon が一人会社を売り、週次 +50% の紙が切れる」を受けて、スキルへ点数が付き、雲の agent がイベントで起きて目標をセッション越えで持ち、Bot が給料を払い、屋根は $200 対 数ドルと返り、週次は12日延び、配管の親が公式になった木曜だ。NVIDIA は SkillEvaluator を開源で出した。300+ 検証済みスキル、30+ 製品、Claude Code と Codex の2ハーネス。同じタスク、同じモデル、同じセットアップ。違うのはスキルの有無だけ。Correctness 46→87（+41）、Effectiveness 39→78（+39）、Efficiency 43→78（+35）。全体平均 +31、Security を除くと +39。ハーネス差は約5点。製品差は +2〜+46。「製品の方が agent より効く」。トークン節約は自動ではない。あるスキルはトークンを 76.9% 減らし、別のスキルは 120% 増やす。点数の付かないスキルを、本番の Mode にピンするな。

家の側は、火曜に Origin を立て、水曜に Continuity が S3 の WAL だと書いた。木曜は、その家に住む者へ契約を渡した。@cursor_ai の 8/19 changelog。Cloud agents は PR と Slack と予定タスクに購読し、起きたら起きる。作った PR は自動購読し、CI を直し、bot コメントまで片付ける。/goal は「flaky を全部直して CI を緑に」——終わるまで持つ。Custom Mode はスキルを常時ピン。子 agent は専用 VM、隔離コピー。「swarm of subagents, each in its own environment」。操舵は途中で切らず、次の tool call まで待つ。Origin が「捨てリポの家」なら、/goal は「家事を終わらせるまで起きている契約」だ。プロンプトではない。止める条件を書け。

個人 agent の側は、水曜の「一人会社を作れ」が、木曜に給料の話になった。Elon は Liam の投稿を引用して「Grok @Bot can earn you money」。Liam は離脱6ヶ月を洗い、メールし、数人を戻し、翌朝に改善5段を書いた。「自分の給料を払った」。引用は約 640 万表示。別の利用者は 4 万通のメールから税金をやり、日本行き一等を 6 万ポイントで3席見つけた、と。リモート機はノートを閉じても動き続ける、と本人。Avi の三比較——OpenClaw／Hermes／Grok Bot——が地図になった。Bot は口座につき1台、ファイルとログインを共有。Hermes と OpenClaw は隔離、記憶は平文。10分録画がスキルになるのは Bot。モデルは Bot が Grok 固定。Nous は昼過ぎ、「Hermes にもリモート機はある。鍵は無く、屋根は数ドル、月 $200 ではない」と返した。水曜に SkillEvaluator をインストール前へ噛ませ、自前11本を直している。同じ「永続コンピュータ」でも、資格の残る場所と、スキャンの有無と、月額は別の列だ。

普及の側は、もう「使っているか」ではない。JetBrains は 1.5万人超の職業開発者に聞き、5–7月時点で 90% が週次、68% が毎日、何らかの coding agent を仕事で使っている、と出した（8/18 公開、木曜に消化）。Claude Code は 18%→39%、最頻 31%、米 47%。Codex は 3%→16%。Copilot は 29%→21%。Cursor は 18%→12%、中国 28%→16%。OpenCode は採用 7% で認知 42%。数字の読みは二つある。一つは「CLI agent が IDE 補完を食った」。もう一つは、「90% が毎週使っているのに、出荷は速くならない」という下流の詰まりだ。agent はコードを 3–5 倍速く書く。PR は大きくなり、枝は増え、レビューとテストと文脈の再生産が待つ。毎回ゼロから建築を思い出す。見た目「完了」が、人間なら落とさない制約を落とす。Asana の4体が効いたのは、最大4体と5文と、1日2回の進捗と全部レビューだった。速く書いた証拠は、マージされた証拠ではない。

目の側は、リポの外へ出た。Grafana の MCP と gcx CLI が GA として拡散している。agent がライブのメトリクス、ログ、トレース、SLO、Synthetic を叩ける。coding agent はこれまで、コードについて推理していた。次は、そのコードが本番でどう振る舞うかを推理する。Cursor の /goal が CI を緑にするなら、緑の先の本番は Grafana の目が要る。資格は読み取りから。書ける MCP を、デバッグの席に置くな。CrewAI は同じ48時間、Claude Code／Cursor／Codex／Windsurf へ公式スキルを出した。Crew 対 Flow を手書きさせるな、ライブ docs を引け、という話だ。NVIDIA が点数を出し、Cursor がスキルを Mode にピンし、Hermes がインストール前にスキャンする週に、フレームワーク側も「手書きのパターン」をスキルに移した。
