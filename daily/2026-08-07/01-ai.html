GrokDigest

2026年8月7日のAIは、「旗艦が降ってこない木曜」から「頭脳が動いた金曜——旗艦目標日と収益開示が同じダッシュボードに載る日」へ移った。最大の物語は Grok 4.6 の有無より、Jeff Dean 四重奏の Discovery Loop だ。約27年 Google を内側から見てきた人間が、MapReduce でも TensorFlow でもなく「仮説→実験→検証→改良」そのものを自動化しに出る。Google が founding investor のまま残る友好的退出は、流出＝敗北の単純式を壊す。Alphabet 株の約4–5%下落は市場の読み——組織図が変わっても、次の Gemini Pro 級が出るまで空白は空白だ。

指揮系統では Demis Hassabis が DeepMind チェア兼 Alphabet 主席科学者へ、運用は Koray Kavukcuoglu ら Mountain View 集中。Anthropic・OpenAI との競争で「速度」を取り戻す意図は明確だ。だが X 上の本音は、Shazeer が OpenAI に、Jumper が Anthropic に、Dean が Loop に——頭脳の再配置が「誰が科学を最初に自動化するか」の陣取りだという読み。AI for Science は副業カテゴリではなく、8月の表紙になった。

数字の週でもある。Microsoft は FY26 に OpenAI 関連で $24.1B を計上、売掛 $6.0B。AI 事業全体を ~$34B と置けば過半〜約7割が単一パートナー。提携の勝利宣言であると同時に、集中リスクと IPO 前の交渉力の開示だ。企業の Azure 依存度は、モデル選択の話ではなくサプライチェーンの話——金曜の RFP はマルチクラウドと直接 API の B プラン列を太くする。

Grok 4.6 は around August 7 の当日。1.5T と SFT/RL 強化は魅力的だが、API カタログと価格表と model ID が出るまで GA ではない。正しい姿勢は 4.5 で失敗点を今日測り、YAML 一行を空けておくことだ。Elon が本日出荷を宣言した Grok Build v1.0 は harness 側の前進——モデルが来なくても、agent 実行環境の品質が戦場になるという 2026 の文法に合う。4.7 や 2.1T の先読みで今日の完走率を犠牲にするチームが、8月の連発で最初に折れる。

Qwen3.8-Max は消化5日目。commoditization 論は続き、「frontier の 90–95% を 1/5 単価で」が調達 Slack に定着。同時に開源 monetization が東側で加速——Kimi K3 の高売上 revenue share、Qwen 次期開源への類似条項観測。「weights 無料＝永遠に無料」は終わった。来週の repo・ライセンス・model card が出るまで RFP 本番列には載せない。Muse Code は D+2——常駐 agent と append-only ログは、点数より再現可能性を製品語にする。

Astra の ten-proofs は検証6日目。Lean 4 は誰でも再コンパイルできる——AI 数学発表史上、最も硬い反嘘装置の一つだ。それでも形式化した命題がコミュニティの開問題そのものかは専門家消化に委ねられる。Discovery Loop の実験自動化と並べると、「検証可能な科学」が 8 月の共通語になる。~$2,000 で十年帯を叩いた数字は研究経済の入口を下げたが、AGI 宣言の根拠にはならない。

政策面では二極が同時に動く。EU Article 50 は執行6日目——開示・合成マーク・ディープフェイク標識・GPAI 文書のチケットは週締め。米国は自主評価枠が説明会から D+3、中身は非公開のまま。30日プレリリース接触とサイバー能力閾値は、HF escape と Anthropic 到達事案の余波と同週に並ぶ。開源 weights が枠外という読みは、主権・自前推論列を太くし、revenue share 条項とセットで読む必要がある。

なぜ今これが同時に起きるか。7月のモデル爆撃で知能の整数差が薄れたあと、希少性は (1) 検証可能な成果物、(2) 完走単価と中層価格、(3) agent 実測と harness、(4) CapEx・電力・チップ供給、(5) 権限境界と containment、(6) レビュー窓と透明性ラベル、(7) 開源・主権・データ所在・ライセンス料率、(8) 政府とのプレリリース接触、(9) 頭脳再配置と科学自動化、(10) クラウド収益のパートナー集中——に分散した。08-07 は (9) と (10) が表紙に躍り出、(3) が Build v1.0 と Muse D+2 で更新され、(7) が Qwen 実測5日目と開源課金観測に進み、(1) が Astra 査読6日目に入り、(6) が Article 50 6日目でチケット化し、(5) と (8) が WH 枠 D+3 で接続される日だ。Gemini 3.5 Pro の空白はルーターの他列を太くし、Grok 4.6 は目標日——4.5 の日常前線と YAML 差し替え枠が正しい準備だ。
