長時間実行の信頼は、会話履歴を信じる設計から離れる。LongHorizon-Harness の manager／fresh executor／read-only auditor は、永続メモリを「検証済みタスク状態」に置き換える。火曜の「失敗を恒久回帰テストに」は、Harness-R1（失敗軌跡→実行可能パッチ、ターゲット凍結）と HarnessCompass（汎化ゲート・自己申告検証・code/criteria 分岐）として、殻を自動で直す論文群に育った。agent が壊れるのはデモの翌日——だから壊れた軌跡を訓練データにしろ、という話だ。

囲い込みへのカウンターも水曜に具体化した。LangChain Deep Agents Code は任意モデル向けの Claude Code 相当 CLI を OSS で出し、サブ agent 隔離・filesystem・HITL・Ollama/vLLM を既定に持つ。火曜の OpenWork と同方向——手足は MCP とスキルで差し替え可能であるべき、という市場圧力。その裏で Codex に custom MCP がないという辛口、~/.agents/skills を見ないベンダーへの goodwill 減点が続き、スキルパス標準戦争は終わらない。
