GrokDigest

2026年8月15日の AI は、金曜の「人間の承認をクリックから外す」と「閉じた防御モデルに開いた数字をぶつける」の翌日に、「日々開くコーディングの箱の所有者が変わった」を重ねた。@cursor_ai の一文は短い。「Cursor is now part of @SpaceX. Today, we have officially closed our acquisition」。約 50,000 いいね、約 700 万表示。4 月 21 日のオプション、6 月 16 日の $60B 全株式合意、8 月 14 日のクローズ。対価は SpaceX Class A 約 3.893 億株。合併子会社は X67。チームは SpaceXAI に入り、Grok Build と Grok Bot と Grok API と Cursor を同じ屋根の下で直す、と本人が書いた。木曜には Firetiger を受け入れ、cloud agent の起動を builds で 3 倍にした。金曜に親会社がロケット会社になった。土曜の現場が書くべきなのは祝辞ではなく、データ処理条項とモデル学習オプトとサポート窓口の差し替えである。

同じ 48 時間で、その箱の中のモデル面も動いた。GitHub は Grok 4.6 を Copilot（VS Code／JetBrains／CLI）に載せた。Enterprise／Business は管理者の opt-in。着地 3 日目の 4.6 が、世界で一番多い IDE の選択肢に並ぶ。Anthropic は予告どおり Claude Code の auto を Pro／Max／Team の新規既定にした。承認プロンプトは消え、分類器が不可逆・破壊・環境外を見る。対照実験は変わらず——有料テスター 1,053 人は危険コマンドの 13.6% しか止めず、auto は 89%。Lydia Hallie の公式ガイドは、同じ金曜に「同じタスクでもセッションの持ち方で請求が倍になる」と書いた。effort を途中で変えるな。Read の代わりに @ しろ。休憩前に /compact。キャッシュは 1 時間で死ぬ。人間が見たつもりは、金曜に監査から外された。土曜は分類器ログを残す側だ。

開いた側は、能力の出荷と料金の時間割を同時に出した。Z.ai の GLM-5.3 はベースを 743B のまま据え置き、伸びを全部ポストトレーニングに置いた。Terminal-Bench 3.0 は 4.6 から 28.3。DeepSWE は 66.9。CyberGym 84.5% は Mythos 5 の 83.8% を自己申告でわずかに上回り、ExploitBench は 54.4% 対 78.0% で負ける。Coding Plan は 5.2／5.1 呼び出しを 5.3 にリダイレクトする——便利だが A/B が壊れる。重みは約 2 週間後。DeepSeek は V4-Pro を GA し、Harness を「全部プラグイン」で開源し、明日 16:00 UTC にピーク／オフピークを始める。V4-Pro のキャッシュヒットは $0.003625 からピーク $0.044、最大約 +1,114%。出力は $0.87 から $1.98／$3.96。開源最安の物語が、容量制約のピーク料金に変わる夜だ。Qwen 3.8 27B は Apache 2.0 で視覚と 262K を乗せ、HN を約 1,090 点で占拠した。743B と 27B を同じ棚に置くな。

閉じた側の速さは、新モデルではなく特権である。OpenAI と Cerebras は GPT-5.6 Sol Ultrafast を限定プレビューした。最大 750 tok/s、Standard の最大 14 倍、知能は同じ、と公式。料金も GA 日もモデル ID も無い。社内はインシデント応答に使い、Jane Street は「使い方が変わる」と書いた。同じ週に FT は、OpenAI が 7 月に Preparedness チームを解散したと報じた。壊滅リスクを見る部署が、IPO 前の再編で消える。Astra は Critical サイバーを否定できず D+8 で止まったまま。Daybreak Blue／Red は AWS に載せ、Critical は誰にもまだ。上界を自己申告したラボが、上界を見るチームを畳む。調達が聞くべきなのはベンチではなく、「誰が Critical に署名するのか」である。
