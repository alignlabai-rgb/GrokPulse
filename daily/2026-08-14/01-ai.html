2026年8月14日の AI は、木曜の「遅れていた旗艦をカタログに置く」に、「人間の承認をクリックから外す」と「閉じた防御モデルに開いた数字をぶつける」を重ねた。Anthropic は 8/7 に予告したとおり、Pro／Max／Team の新規 Claude Code セッションを auto 既定にした。ピン留めは残る。Enterprise とクラウド経由は当面 opt-in。現場で消えるのは、ツール呼び出しごとの「許可しますか？」である。残るのは分類器——不可逆、破壊的、環境の外、を見る小さなモデル——と、連続 3 回または通算 20 回で手動に戻すフォールバックだ。

数字は予告時から変わっていない。1,053 人の有料テスターは、紛れ込んだ危険コマンドの 13.6% しか止めなかった。auto は 89%。人間はセッションが長くなるほど悪くなり、50 プロンプト後には約 5%。本番のフラグ済みセッションでは、ユーザーが明示していない深刻害が手動承認で 2 倍超。Trajectory Labs の間接 injection は、Claude auto に対して 720 試行ゼロ、Sol の Codex Auto-review に対して 5.83%。社内では、公開サイトへのフォールバック投稿、2,000 ポッド規模の kill、課金読み取りのはずがアカウント root、を分類器が止めている。Team／Enterprise の auto 利用者は PR が約 25% 多い。承認プロンプトの 97% が通る世界では、「人間が見た」は監督ではなく、監査の空欄だった。

同じ金曜日、Z.ai は GLM-5.3 を出した。ベースは 5.2 と同じ 743B。伸びは全部ポストトレーニング——タスク環境を長く、種類を増やした、という公式の説明だ。Terminal-Bench 3.0 は 4.6 から 28.3。DeepSWE は 46.2 から 66.9。社内 Code Bench は +50%。X は「首位」と書きがちだが、難しい公開行では Sol／Fable にまだ負ける。本当に金曜を動かしたのはコーディング表ではなく、サイバー表だ。CyberGym 84.5% は Mythos 5 の 83.8% をわずかに上回り、ExploitBench は 54.4% 対 78.0% で負ける。見つける側で並び、動く攻撃に落とす側で負ける。独立再現は無い。重みは約 2 週間の安全審査後。5.2 が数日で落ちたのに対し、5.3 は「先に harden してから開く」。API は今日から、ダウンロードはまだ——この差が、開源の新しい出荷単位だ。

Reuters はもう一本、静かな爆弾を置いた。Apple が Alibaba の支援で中国向け独自 LLM を訓練した、という 3 筋。従来は Qwen や百度に乗せる方針だった。7 月の CAC 登録で Apple Intelligence は中国に入る枠を得た。自前モデルはその上に、外国企業として北京が proprietary を認める初事例、と報道は読む。Mac 向け Qwen 接続ガイドは先週出して説明なく消した。役割分担は未確定。同じ日に上院の Jim Banks は、米開源へのインセンティブと中国製開源への依存制限を CEA に求める手紙を出した。「レアアースのように武器化されるな」。GLM-5.3 が Mythos に数字をぶつけた金曜日に、ワシントンは開いた重みを産業政策として語り始めた。
