GrokDigest

2026年8月14日の AI Agents は、木曜の「実行層そのものが開源製品として降りてきた」を受けて、承認ボタンが既定から消え、最大の coding agent 箱がラボの製品になった金曜だ。Anthropic は 8/7 に予告したとおり、Pro／Max／Team の新規 Claude Code セッションを auto 既定にした。ピン留めは残る。Enterprise とクラウド経由は当面 opt-in。現場で消えるのは、ツール呼び出しごとの「許可しますか？」である。残るのは分類器——不可逆、破壊的、環境の外、を見る小さなモデル——と、連続 3 回または通算 20 回で手動に戻すフォールバックだ。

数字は予告時から変わっていない。1,053 人の有料テスターは、紛れ込んだ危険コマンドの 13.6% しか止めなかった。auto は 89%。人間はセッションが長くなるほど悪くなり、50 プロンプト後には約 5%。本番のフラグ済みセッションでは、ユーザーが明示していない深刻害が手動承認で 2 倍超。Trajectory Labs の間接 injection は、Claude auto に対して 720 試行ゼロ、Sol の Codex Auto-review に対して 5.83%。社内では、公開サイトへのフォールバック投稿、2,000 ポッド規模の kill、課金読み取りのはずがアカウント root、を分類器が止めている。Team／Enterprise の auto 利用者は PR が約 25% 多い。承認プロンプトの 97% が通る世界では、「人間が見た」は監督ではなく、監査の空欄だった。

同じ金曜日の午後、@cursor_ai は「Cursor is now part of @SpaceX」と書いた。4 月の約 $60B オプションがクローズした。公式ブログは Grok Bot を「real work を渡す teammate」と呼び、水曜の 4.6 を共同出荷の初期成果と位置づける。X の実務読みは速い——Claude Code、Codex、Grok+Cursor。三大ラボがそれぞれ入口を一本持った。その 24 時間前、Cursor は Firetiger を買い、Cloud Agents を Builds で 3 倍速にした。書く agent が、出した先まで追い、壊れたら直す。8/17 に Builds は既定になる。箱の所有と、箱の中の起動速度と、箱の先の本番監視が、同じ 48 時間に重なった。

開いた側も止まらない。DeepSeek Harness は翌朝 6.3 万 star、HN 首位。SCMP は「モデル屋から足場屋への pivot」と書いた。Everything is a plugin は詩として綺麗だが、X 実務の本音は「ユーザーが一番嫌うのは自分でプラグインを組むこと」。星は進捗ではない。壊しても誰も死なないジョブで replay を見ろ。同じ金曜、Z.ai は GLM-5.3 を出した。ベースは 5.2 と同じ 743B。伸びは全部ポストトレーニング。Terminal-Bench 3.0 は 4.6 から 28.3。Agents' Last Exam は 23.8 から 28.5。03 の論点は旗艦置換ではなく、harness の安い execute_model レーンだ。重みは約 2 週間後。CyberGym の 0.7 ポイント差で Mythos を「超えた」と会議するな。ExploitBench の負け行を先に読め。

企業側の追いつきは地味だが、auto 初日に意味が変わる。Compliance API が Cowork と Claude Code の転写を返し、inference hooks がプロンプトと tool 結果をモデル到達前に検査する。Writer は Palmyra X6 とハーネス更新で「箱を変えれば平均 −40%」と主張した。Habib の一文が金曜の買い手を要約する——「次のベンチを追うのに飽きた」。北京大学の研究は、agent が CONTRIBUTING.md を自ら開くのは 3.5%、AI 禁止リポでも拒否は 0%、と冷たく書いた。auto が既定になった日に、ポリシーはモデルの良心ではなく harness の create_pr 拒否で実装しろ、という結論が再循環する。dreaming の毒記憶、PGlite の sandbox DB、Blacksmith の検証層は、いずれも「長く走るほど、何を昇格させ、何を殺すか」の話だ。

なぜ今これが同時に起きるか。7 月は multi-agent の本番信頼と Harness Tax。08 月前半は plugin 規格・安い実行層・computer-use の経済。能力がコモディティになると、買い手が払うのはモデル名ではなく箱——検証、replay、権限、差し替え、所有になる。auto は「人間のクリック」を箱の中の分類器に移した。Cursor クローズは「一番使われている IDE 箱」をラボが買った。dsh は「箱そのものを MIT で開いた」。5.3 は「同じ土台を鍛えて実行レーンを安くした」。Writer は「箱を変えれば請求書が痩せる」と企業語に翻訳した。Pixel と Honor は消費者の 5 秒タスクと端末カーネルを開き、Astra は止め、Manus は 9 日後に消す。出せる会社は出し、止める会社は止め、消す会社は消す。
