GrokDigest

2026年7月28日の AI Agents は、月曜の「K3 量産レーン配線」の翌日として、配線したものを測り・縛る日になった。最大の知的イベントは Sentient の Regression Tax だ。Skills を足すと平均成功率は上がる——だが「以前解けていたタスクが落ちる」回帰が、改善の半分以上を食い潰しうる。description osmosis（スキル説明が未呼び出しでも振る舞いを変える）、grounding displacement、verification displacement——三つの失敗モードは、月曜に流行った「Skills を書け」キャンペーンへの冷水であり、同時に本番運用の必須チェックリストになる。book-to-skill で PDF をスキル束に量産する動きが同じ日に伸びているからこそ、量産パイプラインの出口に回帰ベンチを置く必要がある。

実務層では「AI coding as controlled explosion」が再循環した。プロンプトでモデルを説得するより、触れられるファイル・API・インタフェースで爆破半径を先に決める。これは 07-27 の acceptance harness（始めさせ方）と対になる「壊してもいい範囲」の設計だ。Hooks・allowlist・worktree 隔離は、ガバナンス文書ではなく半径の実装。複数 Claude Code セッションが同じリポを同時に触る衝突メモも、「半径ゼロの並列」が危ないことを現場が再学習している。

経済レイヤでは K3 Day+1 が agent ルーターに染みる。Hermes／OpenRouter 経由で K3 を既定にし、キャッシュ 90% 割引を agent ループの主変数にする——月曜の K3→Opus 二段は、火曜に「子 agent を安いレーンへ逃がす」レート制限裁定（Grok 4.5／中堅モデル）へ一般化した。Cursor Start India は cloud agent を現地価格で売る製品サイドの答え。Perplexity Personal Computer はローカル harness を Windows の机に降ろす。spawn 数自慢の週は終わり、完走単価・cap 生存率・ローカル／クラウド分担が KPI になる。

安全と接続では trust gate（読ませる前の検査）、Nomos 型の action 承認、MCP の QA／取引／Docs 面拡大が並ぶ。プロトコルは協調を美しくするが、実行の所有権・ライセンス層はまだ薄い——つなぐほど責任分界が要る。Anthropic の三要素＋loop（環境・ツール・system prompt）の再解説は、四層 OS や Dynamic Workflows の下にある骨格を思い出させる。複雑さは後から足せ。骨格を太らせるな。
