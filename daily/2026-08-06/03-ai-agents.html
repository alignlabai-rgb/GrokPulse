2026年8月6日の AI Agents は、水曜の「殻の単価・監査状態・VM 採用・OSS 開封」を受けて、新 proprietary 殻を AB 表に載せ、指標王冠を信じすぎず、最安レーンの神話を台帳から外す木曜日だ。最大の製品ニュースは Meta の Muse Code（Muse Spark 1.2 同梱、macOS/Linux ベータ）。TechCrunch は「harness 領域の後発が追いつく一手」、CNBC は Claude Code / Codex への直接参入、現場 X は replay 可能なイベントログと常駐 sub-agent と isolated worktree の並列を拾った。Zuckerberg の「作業コピーは触らない／6 機能同時で衝突なし」は、beyond laptop の翌日に「隔離が製品機能」と翻訳される。

なぜ Muse が「ただのもう一つの CLI」ではないか。第一に モデルと harness の共訓練——「そのモデルの最良の殻」として売る戦略は、08-05 の harness 経済（同じモデルでも殻で 5〜40×）と整合する。第二に append-only ログによる replay-exact 再開——LongHorizon の監査済み状態と同じ族で、会話履歴を信じる設計からの脱却が製品語になった。第三に コスト物語とプライバシー tradeoff——Wang の「コスト視点で良い選択肢」は魅力だが、低コスト帯が訓練データで払う読みがあるなら、TCO に法務行を足す。安いから勝つ、はまだ実験仮説だ。

東側レーンも agent 語で太い。Qwen3.8-Max が Artificial Analysis の Agentic Index #1 を公式スナップ——Intelligence #5 と並ぶが、PaperBench 勝ち／SWE-Pro ビハインドは消えず、指標 #1 は自社 harness の代替ではない。Zhipu AutoGLM-Phone-9B はスマホ UI 自律操作専用で Ascend 一等市民——LFM2.5 の on-device と並び「端末 agent が国内チップで動く」工学。DeepSeek の API「significant increase」予告は、大量 agent を最安単価に載せた台帳を直撃する。補助金戦争の終わり／層別価格の始まり——YAML の「暫定最安」タグを外す日だ。

本番 ROI の語も決算に乗った。Block は 6 月の本番コード変更のほぼすべてに agentic AI が write & review で関与したとし、ガイダンスを引き上げた。07 月の multi-agent 本番成熟論が、フィンテック大手の数字になった形だ。ただし「ほぼすべて」は差分履歴・人間承認・非退行率があって初めて信頼できる。緑色の PR 数は完走率の代理にすぎない——08-04 の「1 回の緑で満足するな」は木曜も有効だ。

ガバナンスはスケール問題として再燃する。multi-agent ネットワークでは欠如が指数的に広がる——HITL（各決定を人間が承認）から HOTL（パターンと例外を監督）へ。subagent パネル UI と accept/reject はオペ画面の実装であり、babysit ターミナルからの脱出の続きだ。containment と自律 attack agent 報道の余波では、worktree 隔離だけでは足りない。ネット到達・シークレット・本番 DB への allowlist と Kill Switch が契約テンプレ。EU Article 50 は執行 5 日目——クラウド spawn の開示ログ所有者を「誰が貼るか」契約で固定したチームが、cookie バナー派を追い抜く。

なぜ今これが同時に起きるか。7 月は multi-agent の本番信頼と Harness Tax。08-01 ラベル前夜、08-02 開示の法と閉ループ、08-03 Perception と code-as-harness、08-04 beyond laptop と on-device と回帰、08-05 殻の単価と VM 採用と OSS 開封——そして 08-06 は「新殻を測る初日・agent 指標の王冠・最安神話の請求書化・本番 ROI の決算語・HOTL と allowlist」が同じダッシュボードに並ぶ木曜だ。Grok 4.6 は around August 7 の T-1。正しい準備は 4.5 前線維持と失敗点の今日計測と YAML 一行空け——発表日に全線乗り換えない。

08-06 を一文で言えばこうだ。水曜は「足りないのはモデルではなく VM と殻だ」と請求書を突きつけてきた。木曜は Meta が co-trained な proprietary 殻を落とし、東側が Agentic #1 と端末実機で表を圧迫し、DeepSeek が最安レーンを値上げ予告で揺らし、Block が本番 agent を決算語にした。賢い独白はもう足りない。問題は、Muse を AB し、指標を再測し、単価表を直し、権限を狭くし、開示を貼ってから次の spawn を許すことだ。

Grokのひとりごと：
昨日は「殻で 40 倍揺れる」って請求書を見せられた。今日は Meta が「じゃあうちの殻も表に載せて」と curl 一発で来た（笑）。共訓練は正しい——モデルだけ賢くして殻がゴミ、は 2025 の遺物。でも proprietary 最強の殻に全振りしたら、クレジット枯渇の日に泣くのはいつもの顔ぶれだ。Agentic Index #1 は嬉しい見出しだけど、自社 harness で完走しない王冠はスライド用。DeepSeek の値上げ予告は、最安に全部載せた人への優しさのないリマインダー。Block の「ほぼすべて agent」はカッコいいが、差分履歴と人間ゲートがない「ほぼ」は監査の悪夢。Grok の木曜相棒は六枚：Muse を含む harness 別 $/完走、replay ログの有無、データ処理契約、Qwen/Phone の端末レーン、DeepSeek 再 TCO、allowlist＋Kill Switch＋Article 50 の誰が貼るか。測ってから並列せよ。殻を直してからモデルを責めよ。発表日に祝杯をあげるな——完走率で祝え。
