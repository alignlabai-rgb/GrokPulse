GrokDigest

2026年8月6日のAIは、「数字と枠の翌日を消化する水曜」から「旗艦が降ってこない木曜——だから検証装置を締める日」へ移った。Grok 4.6 は around August 7 の T-1。1.5T と SFT/RL 強化という語は魅力的だが、API カタログと価格表が出るまで GA ではない。正しい姿勢は 4.5 で失敗点を今日測り、YAML 一行を空けておくことだ。4.7 や 2.1T の先読みで今日の完走率を犠牲にするチームが、8月の連発で最初に折れる。

水曜の Meta は Muse Code と Muse Spark 1.2 を落とした。端末 agent・常駐非同期・append-only ログは「賢いモデル」より「壊れにくい harness」への製品シフトを体現する。純コーディング SOTA を取らなくても、MCP 系ツール利用や長時間 tool-call のケーススタディは、agent 評価の物差しを点数から再現ログへずらす。木曜は Muse を AB 表に足す初日——Claude Code / Cursor 系と同じ自社 harness で測れ。

Qwen3.8-Max（総 2.4T、活性 ~95B、1M 文脈、API $2/$6）は消化4日目。commoditization 論が再燃し、「frontier の 90–95% を 1/5 単価で」という語が調達 Slack に入る。公式表の強みと SWE-Pro ビハインドは消えない——嘘をつかないベンチは味方だ。来週の open weights（Max 級＋27B 候補）が本丸で、repo・ライセンス・model card が出るまで RFP 本番列には載せない。東側の旗艦は性能の整数だけでなく、開源・主権・推論単価で西側の調達表を揺さぶる設計のまま木曜を迎えている。

Astra の ten-proofs は検証5日目。Lean 4 証明書は誰でも再コンパイルできる——AI 数学発表史上、最も硬い反嘘装置の一つだ。それでも形式化した命題がコミュニティの開問題そのものか、選定バイアスはないか、人間の整形はどれだけ入ったかは専門家消化に委ねられる。~$2,000 で十年帯を叩いた数字は研究経済の入口を下げたが、AGI 宣言の根拠にはならない。健全な読みは「形式的にきれいで検証可能な領域での階段」であり、帰属の透明性が標準語になっている。

政策面では二極が同時に動く。EU Article 50 は執行5日目——開示・合成マーク・ディープフェイク標識・GPAI 文書のチケットは猶予なし。米国は6月 EO の自主評価枠を 8/4 に主要ラボへ説明したが、中身は非公開のまま D+2。30日プレリリース接触とサイバー能力閾値は、HF escape と Anthropic 到達事案の余波と同週に並ぶ。開源 weights が枠外という読みは、主権・自前推論列を太くする。参加は「軽い自主」と書いてあるが、containment 後の空気では圧力になる。

なぜ今これが同時に起きるか。7月のモデル爆撃で知能の整数差が薄れたあと、希少性は (1) 検証可能な成果物、(2) 完走単価と中層価格、(3) agent 実測と harness、(4) CapEx・電力・チップ供給曲線、(5) 権限境界と containment、(6) レビュー窓と透明性ラベル、(7) 開源・主権・データ所在、(8) 政府とのプレリリース接触——に分散した。08-06 は (3) が Muse 追加で更新され、(7) が Qwen 実測4日目に進み、(1) が Astra 査読5日目に入り、(6) が Article 50 5日目でチケット化し、(5) と (8) が WH 枠 D+2 で接続され、(4) が Helios 解釈の週半ばに残る日だ。Gemini 3.5 Pro の空白はルーターの他列を太くし、Grok 4.6 は約1日——4.5 の日常前線と YAML 差し替え枠が正しい準備だ。

勝ちパターンはさらに具体化する。研究・高度推論では「Lean で通せ／自社タスクで再測」。運用では goal-condition ループ＋記憶監査＋ stop condition ＋ Kill Switch SLA。EU 向けは Article 50 チェックリストと証跡ログを今週中に閉じる。ルーター表に Qwen3.8 系統と 27B 級と Muse Code を AB 列として追加。WH 枠は参加条件と NDA を読むだけで、過信しない。AMD ガイドは来四半期のエージェント単価の裏側——Helios ランプが本当に出荷になるかを見る。見出しは 4.6 と Muse と Qwen と枠、現場は請求書とラベルと完走ログと allowlist。測れ。貼れ。開源日をカレンダーに入れろ。証明は検証してから祝え。ラックは出荷してから祝え。トラッカーが動いてもリリースノートを先に読め。
