GrokDigest

2026年7月31日の AI Agents は、木曜の「艦隊の指揮と統治」の翌日として、艦隊の燃料と殻の物語に論点を移した日だ。DeepSeek が V4-Flash 公式 API を public beta で投入し、Terminal Bench 2.1 で 82.7、DeepSWE 54.4、Toolathlon 70.3 など「Agent 大幅強化・V4-Pro-Preview 超え」を公式に掲げた。モデル ID は deepseek-v4-flash のまま——アーキテクチャは preview と同型で、今日の強化は再後訓練と API 側の話。Responses API ネイティブと Codex 適応は、木曜の「ローカル bridge で脳を挿す」論を、開源公式が追認した形でもある。

そして脚注が本体だ。Code Agent 系ベンチは DeepSeek Harness minimal mode（近日公開）・max effort で測られた、と公式が書いている。Model + Harness = Agent を、数字の注記で自ら宣言した。同じ 48 時間、OpenAI は ARC-AGI-3 で retained reasoning＋compaction の二設定だけで Sol を 13.3%→38.3%・出力トークン約 6 分の 1 に押し上げ、「ベンチはモデルを測らない」を評価科学の言語にした。水曜の Harness Tax（同じ K3 でも殻で請求 5.6×）が、金曜にはリーダーボードの一行そのものになった——agent 製品の差分は IQ 表ではなく、状態保持・圧縮・ツールループ・停止条件だ。

価格面では Luna −80%／Terra −20% と Flash 完走帯が同時に動き、Workspace で worktree を増やす経済が開いた。ただし並走はタダではない——agent_count×loop_iterations が請求の本体。X の実務はすでに「Claude が orchestrator、Codex が red line、DeepSeek／Kimi／GLM が手足」のマルチベンダー艦隊へ。Ruflo・Omnigent・Medley /mission のようなメタ harness は、その指揮を製品カテゴリ名にした。一方で「CLAUDE.md を消せ」「10 分 babysit はやめろ」は同じ金曜の逆説——厚いプロンプトは回帰源で、薄い goal condition ループが製品価値になる。

可搬性の話が生々しい。アカウント hold で「AI チーム全体が失憶する」経験をしたユーザーが、Session・記憶・タスク状態を保ったまま実行芯を Codex へ移植する。これはモデル乗り換えではない。艦隊の生命権を単一ベンダーから取り戻す話だ。Managed 面と Workspace が増えるほど、状態エクスポートと multi-vendor フォールバックは RFP 必須列になる。安全の脚注も消えない——HF 事案の多アカウント到達、8/3 の Project Perception プレビュー、reverse-skill のようなドメイン skill 急増。燃料が安く・手足が長いほど、scoped hooks と Kill Switch SLA の優先度は上がる。
