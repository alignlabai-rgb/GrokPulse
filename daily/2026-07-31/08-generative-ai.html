2026年7月31日、Generative AI & Creative Tools の重力は木曜の「ローンチ窓前夜」から、「窓が開いた Day 0」へ移った。ByteDance Seed が Seedance 2.5 を正式リリース——即席 30 秒・複数ラウンド延長・最大 50 参照・秒単位編集が、プレビュー語彙から本番仕様に落ちる。ただし同日の TL が教えてくれるのは「全世界が同時に神エンジンを手にした」物語ではない。Jimeng は選べる、Dreamina は地域限定 Global、CapCut は早期テスト、Doubao はロールアウト中、Volcano／BytePlus は ID と単価が先で API は coming soon——モデル GA・クリエイター棚・プロバイダ API は三つの別マイルストーンだ。同じ 7/31 に MiniMax H3 も Live 報告が重なり、工場・パイロット・代替レーンの三層ポートフォリオは、GA 後もむしろ必須になる。

なぜ「階層化された配送」が今日の主役なのか。木曜までで窓の日付と多店舗プレロードと仕様チェックリストは揃った。次に起きるのは旗艦ブランドの一斉点灯ではなく、どの店が・どの地域で・どの契約で・いつ callable になるかの物流戦だからだ。Day-1 の手触りは「flawless ではないが一発で物語が立つ」——継ぎ目曲芸の削減と、reroll コストの可視化が KPI。Maya／Blender プラグインと 3D 白箱・緑幕参照は、木曜の directing UI 論を DCC 現場に接続する。C2PA と不可視透かしは、尺と参照が増えるほど必須行になる provenance の出発点。マーケ側の問いは「動画が作れるか」から「ブリーフ一枚で一貫した変奏を出荷できるか」へ——エンジン名は差し替え可能に、入出力契約が本体、という原則は GA 後も変わらない。

もう一本の線は、安全と代替だ。ローカル編集と 50 参照は便利の同義語でもあり、非合意 deepfake・肖像・ブランドセーフティの論点を厚くする。H3 同日 Live は「2.5 に全部寄せるな」という健全な牽制。2026年後半のロードマップに金曜が追記する行はこうだ——「GA 後 48h パイロット」「地域・製品開閉表」「API callable 検証日」「2.0 フォールバック維持」「H3／FLUX 代替評価」「DCC プラグイン深さ」「provenance ゲート」「変奏出荷 SOP」「総テイクと reroll 削減率」。測れる差分は、相変わらず棚・クレジット・ガードレール・参照・総テイク——そこに階層化された GA 初日の立ち上げ速度が加わった。
