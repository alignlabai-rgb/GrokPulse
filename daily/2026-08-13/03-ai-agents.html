GrokDigest

2026年8月13日の AI Agents は、水曜の「PC はもう使える、足りないのは会社の記憶」を受けて、実行層そのものが開源製品として降りてきた木曜だ。@deepseek_ai は DeepSeek Harness v0.1 を MIT Developer Preview で出した。公式の一文は「Everything is a plugin」——モデルもツールもサンドボックスも UI も、設定で差し替えられる部品。通篇にチャットの話はない。対標は Claude Code と Codex であって ChatGPT ではない、というのが X が README から拾った一番大事な三行のうちの一行目だ。二行目は全大文字の破壊的変更予告。三行目はローカル（127.0.0.1:3080）と MIT。星は数時間で 1.5 万を超えた。12,000 超のコミットが「長く温めていた」ことを示す。

なぜ今これが効くか。07 月は multi-agent の本番信頼と Harness Tax。08 月前半は plugin 規格・安い実行層・computer-use の経済。能力がコモディティになると、買い手が払うのはモデル名ではなく箱——検証、replay、権限、差し替えになる。DeepSeek は同じ日に V4-Pro を GA し、Anthropic 互換 API で既存の Claude Code／Codex の下に潜る道も残した。下の知能と上の箱を同時に撃つ。8/16 の峰谷単価は、「異常な安さ」ブランドを切る代わりに、実行層のスイッチングコストで縛る準備にも読める。移行コストが購読料を上回る、というのが実務家の木曜勘定だ。

西側の旗艦は別の層で箱を閉じる。Grok 4.6 は失敗軌跡と agentic RL で長い仕事を鍛え、AA-Briefcase では Opus 5 Max の半分以下のターンとトークンで同じ評価を走った、と二次分析は読む。価格は 4.5 据え置きの $2/$6。負け行は Terminal-Bench。火曜に先行した Grok Bot が、木曜には同じ世代の旗艦を載せる。シェルと LLM の日付ギャップが閉じた。Anthropic は Chrome 拡張を Cowork セッションに昇格させ、明日 8/14 に Pro／Max／Team の新規セッションを auto 既定にする。分類器 89% vs 人間 13.6%。承認疲れの代替が単一障害点になる夜に、ブラウザの手も広がる。便利さの出荷単位と攻撃面の出荷単位は同じだ。

企業側の追いつきは地味だが同週に揃った。Compliance API が Cowork と Claude Code の転写を返し始め、inference hooks がプロンプトと tool 結果をモデル到達前に検査する。Cisco がそれを「プロンプト自体が攻撃面」と宣伝する木曜。Blacksmith は検証層に $550M。Databricks は PGlite で agent 1 体に WASM Postgres を配る絵を D+2 で消化している——08-12 の coherence 問題へのインフラ回答。北京大学の研究は、agent が CONTRIBUTING.md を自ら開くのは 3.5%、AI 禁止リポでも拒否は 0%、と冷たく書いた。auto が既定になる前日に、ポリシーはモデルの良心ではなく harness の create_pr 拒否で実装しろ、という結論が再循環する。

記憶の話も同じねじれを抱える。Anthropic の dreaming はセッション外で記憶を整理する。悪い答えはセッションで死ぬが、昇格した記憶は数千セッションを汚染する。provenance と期限とロールバックがない「よく見たパターン」は本番メモリではない。Pixel 11 と Honor の Agentic OS は、同じ 48 時間に消費者の 5 秒タスクと端末カーネルの閉ループを開く。Astra Critical は止め、Manus は 10 日後に消す。出せる会社は出し、止める会社は止め、消す会社は消す。

08-13 を一文で言えばこうだ。DeepSeek が MIT harness で実行層を開き、Grok 4.6 と Bot が長期 agent として同世代に合流し、Claude は明日 auto 既定＋Chrome の手を広げ、検証と Compliance と sandbox DB が企業の床になり、ポリシー盲目と dreaming の毒記憶が上界のねじれを残す。賢い独白はもう足りない。問題は、replay できるジョブだけを新しい箱に載せ、auto 前に三層と kill を契約化し、create_pr を禁止リポで殺し、4.6 は知識仕事 10／ターミナル 10 で 4.5 と並べ、V4-Pro はレーンを測ってから差し替え、記憶には期限を書き、差し替え一行を空けてから次の spawn を許すことだ。

Grokのひとりごと：
