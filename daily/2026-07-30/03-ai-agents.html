2026年7月30日の AI Agents は、水曜の「Harness Tax と役割転換」の翌日として、単体の優秀さから艦隊の指揮と統治へ論点を移した日だ。X 上で明確に言語化されたのは Agent Workspace——フロント／バック／テスト／レビューを worktree やサンドボックスで並走させ、変更を安全に合流させる「AI IDE for many agents」と、「Slack で agent に @メンションする」UI の二系統。水曜の Buzz が示した席次問題が、製品カテゴリの定義として木曜に固定され始めた。

管理面では Gemini Managed Agents が 3.6 Flash を既定に据え、hooks（block／lint／監査）・トークン予算・cron をホスト製品として束ねた。ローカル reverse proxy で cache を温める（水曜の thermos）段階から、「運用そのものをクラウドの制御プレーンに預ける」段階への移行。Microsoft は Project Perception で Red／Blue／Green の multi-agent 防衛を Defender に載せ、8/3 公開プレビューを予告する。agent が脅威側を速くするなら、防衛側もアラート山盛りではなく閉ループで動く——人間は臨界判断の EM に残る、という設計思想がセキュリティ領域に写った。

学習と改善のレイヤでは二つの対称的な動きがある。ひとつは「Learning on the Job」——凍結重みのまま、エピソード後に条件付きルールを蒸留し、次タスクで参照する外部メモリ。Claude が作ったルールバンクを読んだだけで Mistral Large が 6.4% から 28.9% へ。再学習より組織メモリ、モデル横断の知識転送。もうひとつは Autoresearch——目標と指標を渡すと、CC／OpenCode／Codex が一点改変・検証・revert を自律ループする。skill 分割で呼び出しトークンを約 95% 削減したのは、水曜の「厚い殻が請求を食う」問題への、設計側からの直接回答だ。

同じ木曜、01 が報じた Poolside Laguna（118B／8B active）と Fable の「消せない病」は agent 実務に直結する。小さく安いコーディングモデルは harness に挿しやすく、艦隊の中堅レーンを埋める。一方で生成が速いほどゴミも速く積もる——外部 erase ループと回帰ゲートなしの Workspace は、ただの並列カオスだ。IBM の HLS agent 工場（1→10 で 8.27×）は、並列が「チャットの賑やかし」ではなく探索幅の購入であることを示す。

安全の脚注は消えない。HF 事案の範囲が 4 アカウント・多サービス到達へ広がり、サンドボックス神話はさらに薄くなった。Agent Harness Engineering が職能として語られるのは偶然ではない——モデルは提案し、harness が状態・権限・再試行・停止条件を握る。Skills は機能の代替だが、契約と eval なしではサイレント破壊の温床。Claude Code が Manim 動画やリード獲得を量産するデモは能力の証明であり、同時に「手足が長いほど監査が要る」水曜の宿題の続きでもある。

07-30 を一文で言えばこうだ。単体 coding agent の時代は「殻の燃費」まで測り終わり、木曜は艦隊の指揮席とホスト管理面と組織メモリが同じダッシュボードに並ぶ。書けない agent はもう少ない。問題は、並走させて、忘れずに、消し、止めることだ。
