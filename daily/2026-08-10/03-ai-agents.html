同じ月曜、@Alibaba_Qwen は Qwen-MM-Plugins を GitHub に出した。ポイントは新 agent を作らないことだ。Skill＋MCP で画像・動画・文書・OCR・3D/CAD を既存 harness にマウントする——Claude Code、Codex、Qwen Code、Gemini CLI、OpenClaw 想定。X では 26 万 view を超える公式投稿が「From multimodal models → multimodal agents」と宣言した。これは Plugins 1.0 の精神そのもの：能力はパッケージ、実行は殻。同時に冷たい読みも出た——感覚を増やすことと、許可・証跡・ロールバックは別レイヤ。CAD を触れるプラグインに Policy→Receipt→Audit が無ければ、それは unsupervised hands だ。

制御平面と上界の宿題は消えていない。Claude Code の auto mode 既定は 8/14（T-4）——人間 13.6% vs 分類器 89%、権限プロンプト 97% 承認。Plugins 未対応の沈黙と同画面に置くとねじれが見える：Anthropic は「毎回クリック」を捨てる制御平面を先に動かし、拡張互換の業界標準にはまだ座っていない。OpenAI 側は Agents SDK（sandbox、handoffs、guardrails）と Plugins 支持の両輪。Astra Critical D+3 は agentic coding の上界を調達語に残し、NVIDIA NOOA D+1 は class-as-agent と container 必須を AB 表に残す。Grok 4.6 は D+3 でカタログ空枠——Build と 4.5 で測り、差し替え YAML を空ける。
