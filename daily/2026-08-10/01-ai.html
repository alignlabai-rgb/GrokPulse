GrokDigest

2026年8月10日の AI は、「Critical を自社が先に言った日曜」から「誰も優等生になれなかった月曜」へ移った。Future of Life Institute の Summer 2026 AI Safety Index は、9 ラボを 37 指標・6 ドメインで採点し、最高でも Anthropic の C+（2.66）だった。OpenAI は C（2.28）、Google DeepMind は C（2.01）、Meta は D+、xAI・DeepSeek・Mistral は F——米・中・欧から一つずつ。存在論的安全は最悪帯で、誰も C- を超えない。成績は「製品が安全」の保証ではなく、制度・方針・開示の格付けである。それでも企業調達にとっては、ラボの自己 PR より独立指数の方が監査表に載せやすい。

FLI の本丸は順位ではない。上位 4 社——Anthropic、OpenAI、GDM、Meta——が、安全閾値に近づいたら開発を一時停止する過去の誓約を弱めた、あるいは空文化した、という発見だ。金曜〜土曜に OpenAI は Astra の Critical サイバーを排除できないと開示し、強化制御未満の内部活動を止めた。個別事例では枠が動いた。だが業界全体の goalpost は後ろへ動いている——これが月曜の構造的皮肉だ。「自社の枠で止めた」と「業界の枠を緩めた」が同じ週に同居する。契約に「閾値到達時の停止・評価条項」を残すかどうかが、ベンダー選定の差別化軸になる。

同日の第二の表紙は資本の話だ。Sequoia の David Cahn が再提示する式：$1.5T の AI インフラ支出をペイするには、ざっくりデータセンタ TCO と粗利を織り込んで約 $3T の収益が要る。Anthropic と OpenAI の合算 ARR は約 $80B——意味のあるスタートであり、解ではない。ギャップは約 $2.9T。bull ケースは企業導入の初期曲線——Palantir Q2 の +93%、Ode With Anthropic の $1.5B 実装 JV、agent 本番展開の波。bear ケースは 54% 級のトークン効率改善が、採用成長より速く価格を圧縮するシナリオ。Apollo の Torsten Slok は、ハイパースケーラ 4 社のキャッシュフロー未達が S&P 集中リスクになる点を警告する。投資助言ではない。月曜のマクロ骨格だ。

出荷と実装の前線は、週末の続きを営業日に落とす作業だ。Claude Code は 8/14 から Pro／Max／Team で auto mode 既定——残り 4 日。人間の承認疲れより分類器を信じる宣言であり、実務の焦点は三層（injection スキャン→transcript 分類→sandbox）とログ・kill の契約化。Ode は銀行・病院・製造への配線が製品になった PE の金の置き方。NOOA は agent＝1 Python クラスの開源 harness——SWE-bench 82.2% は alpha として強いが、AST≠containment が本丸。Grok 4.6 は around 8/7 の D+3 でカタログ未着、前線は 4.5。Qwen 次期開源には大口商用の収益分配観測——無料 weights は永遠の無料ではない。Sonnet 5 と Kimi sunset は 8/31、21 日。
