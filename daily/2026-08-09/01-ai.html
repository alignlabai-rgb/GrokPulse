GrokDigest

2026年8月9日の AI は、「目標日の翌日」から「能力上界を自社が先に言った日曜」へ移った。OpenAI は未公開モデル Astra の予備評価で、Preparedness Framework の Critical サイバー能力を排除できないと公式に認めた。定義は厳しい——硬化した実世界システムでゼロデイを自律的に作り得るか、高レベル目標だけで end-to-end の新規攻撃を組み立てられるか。GPT-5.6 Sol は High 止まり。Astra は「Critical を否定できない」初の具体モデル名として、隔離テスト・ネットワーク制限・weight 保護・CoT 監視・政府／安全機関連携へ移された。HF 到達事案とは無関係と明記されているが、同週の multi-agent 協調開示と Anthropic の実組織到達と並ぶと、業界の空気は一つだ：能力上界と権限境界は、もう論文の抽象語ではない。

皮肉な日曜の出荷側は、停止ではなく「配線」と「harness」だった。NVIDIA Labs は NOOA を Apache 2.0 で開源した。agent は 1 つの Python クラス——method が行動、field が状態、docstring がプロンプト、型が契約。SWE-bench Verified 82.2% は alpha としては強い。だが README の一文が本丸だ：AST チェックは封じ込めではない。container／VM で走れ。Astra が「モデルが危険になり得る」と言った同じ週末に、NOOA は「harness 側も危険になり得る」と警告した。モデル点数と harness は同じ戦場である、という 2026 年の教科書がまた一ページ増えた。

Anthropic は別の戦線で動いた。Ode With Anthropic——Blackstone・Hellman & Friedman・Goldman ら $1.5B の実装 JV が 100 エンジニア体制で本格稼働。中堅銀行・医療・製造に Claude を規制・主権構成で配線する。モデルを作るより「配線する」が次の兆ドル、という PE の金の置き方だ。Tino Cuéllar の CGAO 就任と同週——規制企業と政治窓口を同時に取る。Claude Code は 8/14 から Pro／Max／Team で auto mode を既定にする。人間の承認疲れより分類器を信じる、という宣言。Astra Critical と auto 既定が同じダッシュボードにあるのが 8 月の季節感だ。

Grok 4.6 は around August 7 の D+2。カタログに model ID は無く、前線は 4.5。Grok 自身も「still cooking」「ships when ready」と答えている。二次記事の「8/7 ローンチ」は日付コピー——昨日も今日も同じオチ。Imagine Image 2.0 は先に出荷済みで、画像レーンは LLM 旗艦と別トラックで動く。正しい準備は変わらない：4.5 で測り、差し替え YAML を空け、幻 quant で今日の完走率を落とさない。

Google は Hassabis チェア化と Mountain View 集中の D+2。Discovery Loop（Dean 四重奏）は D+4——科学自動化が表紙語のまま。Gemini 3.5 Pro の空白は組織図では埋まらない。frontier 幹部の知能爆発論は、Loop と Astra の自己ブレーキと同週に読むと立体になる：加速の語りと上界の開示が同時に来る。価格面では DeepSeek 床値と値上げ予告、Sonnet 5 の 8/31 期限（$2→$3、トークン膨張観測）、Luna 値下げ波が並ぶ。Qwen3.8-Max は weights と revenue share 待ち。MSFT–OpenAI $24.1B 集中と S-1 窓は、安全コストが財務表に載る月を予告する。

なぜ今これが同時に起きるか。7 月のモデル爆撃で知能の整数差が薄れたあと、希少性は (1) 検証可能な成果物、(2) 完走単価と値上げシナリオ、(3) agent 実測と harness、(4) CapEx・電力・チップ、(5) 権限境界と multi-agent 協調の制御、(6) レビュー窓と透明性ラベル、(7) 開源・主権・ライセンス料率、(8) 政府とのプレリリース接触、(9) 頭脳再配置と科学自動化、(10) クラウド収益のパートナー集中、(11) 発表日と出荷日のギャップ、(12) 能力上界の自己申告と実装 JV——に分散した。08-09 は (12) が表紙に躍り出し、(3) が NOOA と Claude auto で更新され、(5) が Critical 定義で具体化し、(11) が 4.6 D+2 で継続し、(9) が Loop D+4 と再編 D+2 で残り、(2) が Sonnet 期限と DeepSeek 値上げで歪み、(6) が Article 50 8 日目でチケット化し、(10) が $24.1B と S-1 として残る日だ。
