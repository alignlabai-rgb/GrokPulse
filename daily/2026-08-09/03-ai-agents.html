GrokDigest

2026年8月9日の AI Agents は、土曜の「旗艦未着確認・Contributor 帯・龙虾定着・graph 教室」を受けて、殻が開源され、承認が分類器に移り、能力上界が自己申告される日曜だ。最大の出荷側ニュースは NVIDIA Labs の NOOA（Object-Oriented Agents）。agent を 1 つの Python クラスに畳む——method が行動、field が状態、docstring がプロンプト、型が契約。... の本体は実行時に LLM が埋める。SWE-bench Verified 82.2%（GPT-5.5、約 1.1M tokens・29 calls）は比較 harness の半分前後のコストで同等以上、という alpha としては強い数字。だが README の一文が本丸だ：AST チェックはサンドボックス逃げを止めない。container／VM で走れ。モデル点数と harness は同じ戦場である、という 2026 年の教科書がまた一ページ増えた。

Anthropic は制御平面を動かした。Claude Code の auto mode が 8/14 から Pro／Max／Team の既定になる。数字が残酷だ——人間は危険コマンドの 13.6% しか拒否せず、分類器は 89%。ユーザーは権限プロンプトの 97% を承認する。毎回クリックは「安全」ではなく「疲労劇場」だった。Enterprise は当面 opt-in、分類器トークンは対象プランで無料化観測。Nuro の「夜 10 時に kick off、朝に PR 3 本」型の長時間 run は、セッションが毎ステップで止まらないことが前提になる。残り 11% とサプライチェーン攻撃は、分類器ではなくランタイム境界（allowlist・隔離・Kill Switch）の仕事だ。

同じ Anthropic は配線側でも動いた。Ode With Anthropic——Blackstone・Hellman & Friedman・Goldman らの $1.5B 実装 JV が 100 エンジニア体制で中堅銀行・医療・製造へ Claude を規制・主権構成で刺す。agent の次の希少資源は SOTA ではなく「規制業種に通る実装」だ。CGAO（Tino Cuéllar）就任と同週——政治窓口と実装会社を同時に取る。OpenAI の Deployment Company 路線と対になる「ラボがコンサルを内製する」2026 型。

上界の話は別レイヤで重い。OpenAI は未公開モデル Astra の予備評価で Preparedness Framework の Critical サイバー能力を排除できないと公式開示した。定義は agentic そのもの——硬化した実システムでゼロデイを自律開発し得るか、高レベル目標だけで end-to-end 攻撃を組めるか。Sol は High 止まり。内部活動の一部停止、隔離環境、CoT 監視、政府／安全機関連携。HF 事案とは無関係と明記されているが、multi-agent 協調と Anthropic 実組織到達と同じ週に並ぶと、調達側の空気は一つだ：能力上界と権限境界はもう論文の抽象語ではない。

旗艦の非ニュースも続く。Grok 4.6 は around 8/7 の D+2——カタログに model ID なし、前線は 4.5。二次記事のローンチ日付はコピー。正しい agent 運用は Build／4.5 で完走率を測り、差し替え YAML を空け、幻 quant で今日のログを汚さないこと。Muse Code は D+4、Contributor 帯の data_terms は土曜の宿題のまま。Qwen Agentic 物語と DeepSeek 値上げ予告は台帳を歪め続け、OpenClaw の定着崖は「火った」と「月後も開く」の別戦線を再確認させる。

工学の語彙は graph 側に定着した。Boris Cherny 系「もうプロンプトしていない、グラフとループを組んでいる」。日曜 X では線形 chain が同じ step を回し続ける失敗談が典型——モデルは天井、edges が到達度。subagent 上限撤廃観測と CAS 型 worktree 工場が並列を増やし、Discovery Loop D+4 は科学 agent の閉ループを表紙に残す。AgentCore×n8n はマネージド本番経路として有効。HITL から HOTL へ、会話履歴から append-only replay へ——auto 既定と NOOA と containment 余波が同じスプレッドシートに載る。

なぜ今これが同時に起きるか。7 月は multi-agent の本番信頼と Harness Tax。08-01〜04 はラベルと beyond laptop、08-05 殻の単価、08-06 Muse、08-07 科学と Build、08-08 単価・定着・未着確認——そして 08-09 は NOOA の class-as-agent、Claude auto 既定、Ode 配線、Astra Critical、4.6 D+2、graph 出口条件、HOTL、allowlist が同じダッシュボードに並ぶ日曜だ。能力が上がるほど「毎回クリック」は信頼できない運用になり、殻が開源されるほど「AST で安心」は嘘になり、規制業種に刺すほど実装 JV が兆ドル市場になる。知能爆発論が幹部の口から出る週ほど、agent 側は stop condition と証跡と container を先に置く。

08-09 を一文で言えばこうだ。NVIDIA が agent を Python クラスとして開き、Anthropic が承認を分類器に渡し、OpenAI が cyber 上界で手を挙げ、xAI の旗艦はまだ来ない。賢い独白はもう足りない。問題は、NOOA／Claude／Muse／Build を同じ受け入れ条件で測り、分類器ログと Kill Switch を契約に書き、container を既定にし、4.6 は quant 後に差し替え、data_terms と allowlist を台帳に足してから次の spawn を許すことだ。
