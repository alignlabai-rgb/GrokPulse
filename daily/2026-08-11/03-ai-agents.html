GrokDigest

2026年8月11日の AI Agents は、月曜の「手足の規格と感覚のプラグイン」を受けて、実行トークンを安くし、端末に常駐させ、防御用 agent を契約商品にし、承認の既定を分類器へ移す火曜だ。表紙の一枚目は NVIDIA の Nemotron 3.5 Lightning。30B パラメータの MoE で活性は約 3B——agent が大半の時間を費やす tool ループと検証を、frontier 価格で回すな、というメッセージを公式製品にした。同日の NeMo Switchyard はステップ単位で努力をルーティングする agentic ルータ。「1 呼び出し＝最大努力」の死を、ハードウェア屋がソフトウェア語で言い切った形だ。

ローカル側では Meta Muse Glimmer 30B が D+1 で消化される。Apache 2.0、単一消費者 GPU、4-bit で 20GB 未満、計画・tool・失敗リカバリを agent 前提で設計した dense モデル。X では「API 請求書ゼロの always-on」物語が強く、一方で独立ベンチでは同帯 Qwen にやや負ける観測も出た——火曜の正しい読みは「SOTA 宣言」ではなく固定費・データ主権・クラウド退避の列を RFP に足すことだ。Lightning（安いクラウド／自前推論の実行層）と Glimmer（手元常駐）は競合というより、plan/execute 分割の両翼になりつつある。

制御と上界は同じダッシュボードに載る。OpenAI は Astra Critical（D+4）で「まだ出せない」を開示した週に、Daybreak Blue／Red と GPT-5.6-Cyber を防御実務向けに配る——攻撃面が Plugins／MM で広がるほど、守備の tool-using agent が商品になる皮肉。下院の rogue agent 質問状は、ジム侵入や sandbox 抜けの空気を調達チェックリストに落とす合図だ。Claude Code は auto 既定まで 3 日。分類器 89% vs 人間 13.6% の数字は再循環し、sandbox 既定 OFF や auto 時の一時解除観測が「既定化の前に設定を固めろ」と煽る。EU 向け Claude 透かしは、agent が吐いたテキストの provenance を製品機能にした——検出の限界付きで。

拡張と安さの宿題も消えていない。Agent Plugins 1.0 は D+1 で実装フェーズ——Anthropic 沈黙は続き、Claude 専用 skill と共通 plugin の二重管理コストが RFP 語になる。Qwen-MM は感覚を殻に刺し、Flash／QwQ の安いレーンは百万トークン agent の請求を殺さない。だが感覚と許可は別レイヤ、安い実行と無制限ループは別問題。四天井（金・時間・tool・副作用）は単価が落ちるほど厳しくせよ、というのが月曜から火曜への連続した実務論だ。NOOA の container 必須、自己改善ループ実験の eval ゲート、framework 役割分担——部品は揃った。つなぎと停止条件が製品になる。

なぜ今これが同時に起きるか。7 月は multi-agent の本番信頼と Harness Tax。8 月前半は殻の単価、auto 既定、Critical 開示、plugin 規格——そして 08-11 は「実行を専門化し、常駐を所有し、防御を配布し、承認を移す」が同じ営業日に並ぶ。能力が上がるほど毎回クリックは信頼できず、触れる面が増えるほど allowlist と四天井が先になり、実行が安くなるほどルータと stop condition が希少資源になる。委譲ナラティブが X を埋め尽くすほど、監視と受け入れ通過率が本物の KPI になる。

08-11 を一文で言えばこうだ。Lightning と Switchyard が plan/execute を公式化し、Glimmer が手元に常駐し、Daybreak Cyber が守備 agent を配り、auto は 3 日後に既定になり、Astra と下院が上界を契約語に残し、Plugins と MM と安いレーンは手足を広げ続ける。賢い独白はもう足りない。問題は、plan_model と execute_model を分けて測り、local／cloud／managed を data_terms に三列で書き、plugin 互換と Claude 専用の二重管理を設計し、四天井と Kill Switch を契約に落とし、auto 前に sandbox とログ保持を固め、差し替え一行を空けてから次の spawn を許すことだ。
