GrokDigest

2026年8月11日の AI は、「Critical を自社が先に言った週末」と「優等生ゼロの月曜」の翌日に、「High を守備側に配る火曜」を重ねた。OpenAI は Astra の Critical サイバーを排除できないと開示し、強化制御未満の内部活動を止めた——D+4。その同じ会社が 8/10、Daybreak を Blue／Red に拡張し GPT-5.6-Cyber を出荷した。内部ベンチで 95% の高度サイバー完遂、Chrome V8 の未知脆弱性 2 件、パートナーは Accenture から Cloudflare まで。政策として読めるのは明快だ：Critical 未満の High は審査付きで防御に配る、Critical はまだ誰にも——含む自社内部の通常研究にも——渡さない。検証は難しい。だが「枠で止める」と「枠の中で配る」を同じ週にやったラボは、まだ少ない。

Anthropic の火曜は二枚のインフラ物語だ。Theseus Infrastructure——Macquarie と GIC がエクイティ、Anthropic がアンカーテナント、系統増強と消費者料金上昇分を 100% 負担——は、ハイパースケーラ借り一辺倒から「床と電力を共有する側」への一歩。金額は非開示だが、Ode $1.5B 実装 JV と同月に並ぶと、配線と物理層が同じ会社の 8 月戦略になる。もう一枚は Claude の不可視透かし。8/2 以降の新規モデルに機械可読マーキングを仕込み、EU AI Act の透明性を製品機能に落とした。検出は起源の証明ではない、と Anthropic 自身が書く——それでも Article 50 の「ラベル義務」が、サポートページの仕様になった日だ。

Meta は Muse Glimmer を Apache 2.0 で落とした。30B・4-bit で一枚の消費者 GPU。計画・ツール・自己検証・失敗リカバリ——ローカル agent のフルスタック。中国開源がトークン消費の過半を取る中での米ラボの反撃であり、API 請求書とデータ出国を嫌うチームへの答えでもある。独立ベンチで測るまで本番列に載せない、という規律は Glimmer にも適用する。だが「端末で agent が回る」が開源の既定になりつつある、という信号ははっきりしている。

政治と資本も同じダッシュボードに載る。下院民主党が Anthropic と OpenAI に rogue agent について質問——夏の containment 連打の議会版。Nvidia とウォール街の $500B 級ファイナンス観測は、Cahn の $3T 収益ギャップ論と並ぶと「資金は来る、売上はまだ」の立体になる。Microsoft Maia 300 の 9 月観測と OpenAI 従業員 $7B テンダーは、S-1 前の財務・チップ雑音。Claude Code auto 既定は残り 3 日。Sonnet 5／Kimi sunset は 20 日。Grok 4.6 は D+4 でカタログ未着——前線は 4.5。Pixel 11 は明日。

なぜ今これが同時に起きるか。7 月のモデル爆撃で知能の整数差が薄れたあと、希少性は (1) 検証可能な成果物、(2) 完走単価と値上げシナリオ、(3) agent 実測と harness、(4) CapEx・電力・チップ、(5) 権限境界と multi-agent 制御、(6) レビュー窓と透明性ラベル、(7) 開源・主権・ライセンス料率、(8) 政府プレリリース接触、(9) 頭脳再配置、(10) クラウド収益のパートナー集中、(11) 発表日と出荷日のギャップ、(12) 能力上界の自己申告と実装 JV、(13) 独立安全指数、(14) インフラ支出と収益のマクロギャップ——に分散し、08-11 はさらに (15) 防御用専用モデルの段階配布（High を誰に渡すか）、(16) ラボの DC 共有と電力負担——が表紙に躍り出た。Daybreak／Astra は (12)(15) を、Theseus は (4)(16) を、透かしは (6) を、Glimmer は (7)(3) を、下院は (5)(8) を、FLI D+1 は (13) を、資金観測は (14) を、auto T-3 は (5) を、価格 20 日は (2) を、4.6 D+4 は (11) を更新する日だ。
