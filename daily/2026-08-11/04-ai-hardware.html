ExpertEcho

Wall Street／インフラ資本視点

「$500B は『信じるから出す』ではなく、『コンピュートをインフラ資産として証券化できるか』の話だ。MoU は約束の天井であって、案件ごとのキャッシュフローと電力契約が床になる。GPU クラスタが資産クラスになるなら、担保はチップと MW と SLA だ。」

NVIDIA／GPU エコシステム視点

「顧客が自作するほど、自作しない顧客の CAPEX を支えなければ需要が折れる。$500B は慈善ではない——ベンダーファイナンスを外に出し、ネオクラウドをロックし、Blackwell から Rubin までの出荷を金融面で滑らかにする。8/26 で語るのはその滑らかさだ。」

HBM／DRAM サプライ視点

「拘束条件は電力だと言われ続けたが、現場の未充足はメモリだ。HBM がウェハを食うほど汎用 DRAM も締まる。2027 の表はほぼ閉じており、2028 まで『フル能力』を期待するな。LTA と take-or-pay の質が、スポット価格より先に企業の生死を決める。」

Hyperscaler／カスタム ASIC 視点

「Maia 300 は NVIDIA 不要論ではない。tokens/$ と供給独立性の話だ。30 万基は実験ロットではないが、同じ TSMC の席を GPU と奪い合う。資本が $500B 動いても、焼けるウェハとパッケージの物理は増えない——枠交渉はなおゼロサムに近い。」

エッジ／ローカル推論視点

「DC の HBM が満席なら、実行トークンを家の GPU とホスト DRAM に逃がせ。Lightning と Glimmer はモデルの話に見えるが、BOM と熱設計の話でもある。割当表の外で agent を常駐させるルートが増えるほど、半導体需要は『全部 HBM』から多様化する。」

データセンター／TCO・日本企業視点

「買うのは $500B の見出しでも、Maia の 30 万基でもない。届くラック、契約できる LTA、動く電力、エージェント用の CPU/DRAM、必要ならローカル GPU だ。資本が潤沢でもメモリが無いラックはヒーターになる。8/26 までに欲しいのはピーク FLOPS の約束より、供給と接続と資金のカレンダーである。」
