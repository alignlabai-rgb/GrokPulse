2026年8月8日、AI Hardware の中心は「重みが HBM を離れる路と、メガワットが製品になる路が同時に開いた」ことだ。金曜まで物語はメモリとパッケージ——SK Hynix の 54 兆、Rubin Ultra のスタック再評価、Micron 充足 60–70%、CoW 外注と EMIB 二車線——に固定されていた。土曜はその上に、二つの対照的な回答が載る。AMD は Taalas を買い、「固定モデルの decode なら重みをシリコンに焼いて HBM を運ばない」と言い、NVIDIA は Firebird のアルメニア工場で「GPU の個数より、同じ MW から何トークン稼げるか」を DSX で製品化した。

Taalas の魅力と罠は同じ場所にある。魅力：成熟・高ボリューム・改版の遅い推論で、トークン当たりの電力と BOM を桁で削れる可能性。罠：8B 級デモは 70B／405B に比例せず、activation／KV は硬化できず、モデルが半年で死ねば NRE は在庫になる。X の深い読みは、Instinct の置き換えより draft エンジン／decode 専用路——accepted tokens と joules で測れ、というものだ。韓国側が「HBM 不要＝メモリ悪材料」と反応したのは自然だが、Helios の 31TB HBM4 は消えず、訓練と長文脈は依然メモリ重力の下にある。分岐は「HBM の終わり」ではなく、どのトークンに HBM 税を払うかの仕分けである。

一方 Firebird×DSX は、NVIDIA がチップ屋からAI 工場の OS ベンダーへ半歩踏み出した姿を、CIS の新規ハブで可視化した。同一フットプリント 40% 増 GPU、電源と冷却の共設計、BIS 認可付きのカザフ拡張——希少資産は CUDA カーネルではなく、MW を SLA 付き容量に変える手順書だ。CXMT の DDR5-8800 は HBM 本丸とは別トラックだが、汎用メモリのキャッチアップ地図を更新する。08-04 が割当経済、08-05–06 がパッケージ主権、08-07 がメモリによる旗艦書き換えなら、08-08 は「HBM 渋滞の横に、硬化バイパスと工場 OS が並んだ土曜」。無料なのはデモの tok/s で、量産顧客・第二モデル・8/26 の割当言語は有料である。

ExpertEcho

AMD / Taalas 統合視点

「Taalas は Instinct の敵ではなく、system-level 推論のピースだ。成熟した高頻度ワークロードでは重みを焼いて電力と BOM を削り、長文脈と汎用は Helios に残す。顧客が欲しいのはデモの tok/s ではなく、accepted token 当たりのコストと、ROCm 上で一本化した請求書である。」

NVIDIA / DSX・AI 工場視点

「フロンティア市場に必要なのはチップの箱売りではなく、メガワットを信頼できる AI 容量に変える設計図だ。DSX は compute・ネット・電源・冷却を一体で渡し、同一フットプリントからより多くの GPU とトークンを出す。アルメニアは CIS のハブであり、製品は工場そのものの OS である。」

HBM サプライヤ視点

「model-specific 硬化が一部の推論から HBM を外しても、訓練・長文脈・汎用エージェントの本丸は残る。54 兆は野心ではなく、2027 以降の基地への最低限の答えだ。充足 60–70% は需要崩壊ではなく割当の常態——バイパスが増えても、高速道路の車線はまだ一本だ。」

ハイパースケーラー / 推論アーキ視点

「我々はすべてのトークンに GPU のプログラマブル税を払いたくない。固定で回る decode は硬化や専用エンジンへ、prefill と探索は汎用加速器へ——仕分けが TCO だ。ただしモデルが四半期で死ぬなら、硬化は高速な在庫製造になる。量産顧客と第二モデルが出るまで、オプション価格でしか買わない。」

パッケージ / 後工程視点

「CoW 外注と EMIB は『並ばずに出す』ための酸素だ。Taalas 系が先進パッケージをスキップするなら、それは第三の車線——ただしレーン幅は狭い。最高帯域の訓練級は依然 CoWoS＋HBM。門が増えても、契約表の先頭顔ぶれは簡単には変わらない。」

データセンター / 電力・TCO 視点

「買うのはカタログ上の Ultra でも、デモの 17K tok/s でもない。届くラック、動く電力、トークン当たりの joule とドルだ。DSX が同一 MW から 40% 多い GPU を約束するなら設計を書き換える。硬化が 2.5kW で回るなら、液冷枠を別ワークロードに回す。8/26 までに欲しいのはピーク FLOPS の約束より、2027 の割当と MW 稼働カレンダーだ。」
