2026年8月8日の AI Agents は、金曜の「科学 agent が表紙に上がり、Grok Build が殻を先に出荷し、graph/loop が職業語になり、AgentCore が視覚フローを本番殻に繋いだ」を受けて、旗艦未着の週末に「殻・単価・定着」を測る土曜だ。最大の非ニュースは Grok 4.6 が API カタログに載っていないこと——around August 7 の翌日に二次記事が「ローンチ」と書いても、model ID が無いなら agent YAML の差し替えは空枠のままが正しい。4.5 前線で失敗点を今日測り、Build 上で完走率をログ化し、4.6 が来たら一行差し替え——発表日に全線乗り換える顔ぶれは、いつも同じだ。

土曜の新味は Muse Contributor 帯の価格解剖だ。入力 $0.10・出力 $0.20 は Claude Code の出力帯より桁で安いが、トレードは「プロンプトとコードを訓練燃料にする」。Standard 帯は 12〜21× 高く、RPM も 60 vs 3000。DeepSeek が significant increase を予告した直後に、Meta が補助金付き最安の椅子を奪った形——commoditization は終わらないが、「安いから勝つ」は data_terms を読んだあとの仮説になった。AB 表の列は harness_id × $/完走 × eval_pass_rate × data_terms。opt-out と社内コードの境界を契約に書けないチームは、Contributor 帯に乗る資格がない。

定着の戦線も動いた。中国圏の即刻データが X で拡散し、OpenClaw（龙虾）の月訪問が WorkBuddy の半分前後という読みが広がった。龙虾は AI Agent を全民級現象にした点火剤としては成功したが、製品の希少資源は初週のバズではなく 30 日後に開くかどうかだ。Tencent の WorkBuddy が日常導線とローカルインストールで残存を狙う構図は、「殻の民主化」の次の章——Manus の資本物語も含め、ユーザーは Meta の話も資本の話も知らず、使えるか・高いか・来週も要るかだけを見る。

工学の語彙は週末もグラフ側にある。X では Google の loops → graphs 無料講座が再拡散——first agent から self-throttling multi-agent まで。Boris Cherny 系「もうプロンプトしていない、グラフとループを組んでいる」と同軸だ。OSS 側では Prime Agent が persistent IPython を唯一の道具にし、履歴をプログラムし subagent を関数呼び出しにする長時間 coding のデモを続ける。Muse の replay-exact と合わせて、「会話履歴を信じるな・append-only を信じろ」が 2026 後半の共通語になる。

艦隊は膨張したまま。Claude Code / Codex / Muse / Build / Cursor——HN の「まだ Cursor？」論争は、企業がトークン補助金と IDE 体験の間で引き裂かれている証拠だ。Qwen3.8-Max の Agentic Index #1 は D+2、weights 前は候補列。DeepSeek 値上げ予告は D+2 で新単価表なし——「暫定最安」タグを YAML から外す。Discovery Loop は D+3 で科学 agent の表紙を維持し、AgentCore×n8n はマネージド本番経路として週末も有効。allowlist と Kill Switch と HOTL は、どの殻を選んでも同じスプレッドシート。
