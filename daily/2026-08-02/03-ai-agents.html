GrokDigest

2026年8月2日の AI Agents は、土曜の「ラベル前夜・attention 三択・SDK スペクトル」をそのまま本番に引きずり込んだDay Zero の日曜だ。EU AI Act Article 50 が適用開始——対話が AI であることの開示、合成コンテンツの機械可読表示、ディープフェイク標識。ガイドラインと実務解説は chatbot・仮想アシスタントに加え AI agents と coding agents を例示する。モデル API 提供者は「開示はアプリ側」と線引きしたまま——出荷者のリリースゲートが、今日から法の対象になる。罰則は最大 €1,500 万または全世界売上 3%。cookie バナーを笑っている暇はない。

同じタイムラインで、実装側は「ループ」を教科書化した。Anthropic 系の plan → build → judge 三 agent 循環が再拡散し、「勝者は最良のモデルではなく最良のループを持つ」が日曜の定型句になった。Claude Code 約 40 万セッションの五段階習熟度は、その裏側を突く——Level 5 はユーザーがモデルを直し、モデルがユーザーをほぼ直さない。agent 製品のボトルネックはベンチ整数ではなく、人間が検証ループに入れる UX と計器盤だ。claude-pulse 型の週次リミット可視化、OpenCode 等の無料エンジン差し替え、OmniRoute 系の 90+ プロバイダ——いずれも「燃料計と代替レーンなしの艦隊」を拒否する動きだ。

殻の戦争も止まらない。DeepSeek Code が Harness 上の coding agent として CC／Codex 土俵に乗る、という日曜言説は、V4-Flash の agent 数字が殻経由だったという整理とセットで読む。公式行と本番行の二表、retained state と compaction——07-31 以来の harness＝製品論が、製品名を増やした。oh-my-claudecode 型メタ殻、Codex portable plugins、Claude 指揮＋多モデル派遣の実務テンプレは D+2 で棚に残る。検索設計では「grep が embedding に勝ち vector なしで ship」が論争を呼び、agent のコード理解が RAG 信仰から測れる検索契約へ戻る。

本線 AI の Astra 十証明は、agent にとっての ideal goal condition を更新した。完了は「良さそう」ではなく Lean／テスト／型／eval のゲート。MCP 一行で金融データや動画生成 skill を手足に付ける動きは agentic finance と creative pipeline を同じ配線図に載せる——そのとき権限は Flash が安いほど狭くしろ。明日 8/3 の Project Perception（Red／Blue／Green）は、plan/build/judge と同型の役割分離を防衛製品に載せる。ラベル初日の翌日に閉ループ防衛が来るカレンダーは、偶然ではなく 8 月の軸だ。

なぜ今これが起きるか。07-07 以降 multi-agent は本番信頼性へ、07-18〜24 は工場規格と請求書、07-25〜30 は診断語彙・Harness Tax・Workspace、07-31 は安い完走燃料と測り方と可搬性、08-01 はラベル前夜と attention 選定、そして 08-02 は開示の法・閉ループの教科書・検証器ゴール・計器盤・coding agent 土俵の拡大。次のボトルネックはフロンティアの順位表ではなく、開示実装・goal/stop/label condition・殻の差し替え・vendor 遅延 B プラン・週次枠の可視化・agent 数に比例する監査コストだ。

08-02 を一文で言えばこうだ。土曜はナンバープレートを用意し、ハンドルの重さと視線の置き所を決めた。日曜はプレートが義務になり、運転は plan/build/judge の周回コースになり、ゴールテープは検証器が持つ。書けない agent はもう少ない。問題は、安く完走させ、開示し、殻を差し替え、権限を狭く保ち、燃料計を見ながら月曜を迎えることだ。
