GrokDigest

2026年8月1日の AI Agents は、金曜の「燃料と殻と可搬性」の翌日として、制度ラベルと実装選定と attention 設計に論点を移した土曜だ。DeepSeek V4-Flash の agent 数字と Codex 互換、OpenAI の Luna −80%／Terra −20%、ARC の retained reasoning＋compaction は、まだルーター表と eval 二表の本体として残っている。だが週末のタイムラインが新しく強調したのは、「agent を出荷する側」が明日 8/2 から負う EU Article 50——AI 対話の開示、合成コンテンツの表示、ディープフェイク標識——である。モデル API は開示を肩代わりしない。cookie バナー化を笑う余裕より、リリースパイプラインにラベルゲートを足すチームが勝つ。

製品カテゴリの言語も土曜らしく整理された。Claude Code／Codex／Antigravity は同じ coding agent 棚に並ぶが、人の attention をループ内に残すか、クラウドに委譲して PR だけ受け取るか、ワークスペース全体の指揮席にするか——トレードオフが逆。SDK は Codex SDK→Claude Agent SDK→OpenAI Agents SDK→Pi の軽重スペクトルで語られ、右へ行くほどカスタムが深くメンテも重い。金曜の「差し替え可能な YAML」は、今日は gravitas の選び方として実装者の言葉になった。

メタ殻と可搬性は止まらない。oh-my-claudecode 型の multi-agent オーケストレーション、Codex Agent Plugins 1.0 の portable plugin.json、Claude 指揮＋Codex／DeepSeek／Kimi／GLM 派遣の実務艦隊——「5 セッション手動はカオス」への答えが製品名を持ち始めた。高エンゲージの workspace 論は、他人のテンプレを捨てて自分の API／MCP／CLI で薄い地図を組め、と言う。厚い CLAUDE.md を焼く話と矛盾しない。独白ではなくツール契約と goal condition だ。

安全と政策の時計も同じダッシュボードにある。WH 事前レビュー枠は 8/1 前後で制度化フェーズに入り、agent の「脳」供給に 30 日遅延リスクを足す。8/3 の Project Perception は防衛側の Red／Blue／Green 閉ループ。HF 事案の爆破半径は、Kill Switch SLA と scoped hooks の根拠として残る。agentic finance 言説は、coding の外側で「手足に財布を持たせる」権限設計を一般化した——金曜の燃料安は、権限を広くする言い訳にはならない。

なぜ今これが起きるか。07-07 以降 multi-agent は本番信頼性へ、07-18〜24 は工場規格と請求書、07-25〜30 は診断語彙・Harness Tax・Workspace・Managed、07-31 は安い完走燃料と測り方と可搬性、そして 08-01 はラベル義務・SDK 選定・attention 三択・メタ殻の棚・政策カレンダー付きレーン表。次のボトルネックは「どのフロンティアが一番賢いか」ではなく、開示実装・殻の gravitas・状態のエクスポート・vendor 遅延 B プラン・permission 一括・agent 数に比例する監査コストだ。

08-01 を一文で言えばこうだ。金曜は燃料の価格表と殻の測り方を書き換えた。土曜は、その艦隊をラベル付きで出荷し、注意の置き所を設計し、SDK の重さを選べ、と制度と実装が同時に言っている。書けない agent はもう少ない。問題は、安く完走させ、開示し、殻を差し替え、権限を狭く保ったまま月曜を迎えることだ。
