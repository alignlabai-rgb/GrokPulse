GrokDigest

2026年8月12日の AI は、火曜の「High を守備に配り Critical を止める」に、「利用者の天井を数える」「実行ステップのルーティングを製品化する」「防御モデルを AWS に載せる」を重ねた。Sundar Pichai が Gemini アプリ 10 億 MAU を宣言した——ChatGPT が 6 月に取った同じ天井に約 2 ヶ月遅れ。音声 63%、日次画像 1.5 億枚、iOS 1 億。Search の AI Mode も別途 10 億だが、今日の数字はスタンドアロンアプリ。Made by Google 本番日の朝に「到達率」の物語を先に置いたのは、意図的かどうかはともかく、効果的だ。

Nvidia の水曜（正確には 8/11 出荷・水曜消化）は、フロンティアを目指す発表ではない。Nemotron 3.5 Lightning は 30B MoE・3B アクティブ——agent が毎秒吐き出す git pull やツール検証や整形のための実行層だ。NeMo Switchyard は「どのリクエストをどのモデルに振るか」を Rust で開源し、OpenRouter／LiteLLM／Kong に埋め込む。Cognition は Devin Desktop で平均コスト −28%。Huang が開源規制緩和を訴えた直後の weights 出荷であり、Meta の Muse Glimmer と同週に並ぶと、「軽いローカル／軽い実行」が米ラボとチップ屋の共通戦場だと分かる。整数のリーダーボードより、トークン予算の配分表の方が現場を動かす。

OpenAI は Daybreak を Amazon Bedrock に載せた。Blue／Red は審査付きのまま、だが「既に AWS でガバナンスしている企業」への配送路が開いた。同じ会社が ChatGPT Ads を英・墨・伯・日・韓へ広げ、Business Premium を $125 で並べる——無料帯は広告、ヘビー席は単価、防御はクラウド。Astra Critical の自己ブレーキ D+5 はウォッチリストのまま。止める・配る・課金する・載せるが、同じダッシュボードに並ぶ。

安全と地政学も止まらない。暗号化 CoT が横断復号できるという論文は、Anthropic／OpenAI／Google の「思考の箱」を攻撃面に変えた。Manus は Meta 買収を北京命令で巻き戻し、8/23 のデータ削除カレンダーをユーザに渡した。下院は rogue agent の書簡を再循環。Claude Code auto 既定は残り 2 日——分類器が人間の承認疲れに勝つ、という内部数字が、CoT 攻撃と同週に並ぶ皮肉。Riot 191MW・CoreWeave $104B backlog・Super Micro 倍増売上は、Theseus 型インフラ物語の続き。Weil の科学 AI スピンアウトと Claude の ζ 下界改善は、「ベンチ以外の知性」の別経路。

勝ちパターンは一段具体化する。利用者到達は Gemini アプリの音声・画像数字を「自社の入口」比較表に。実行コストは Switchyard 型ルーティングを PoC 列に——計画はフロンティア、実行は Lightning／Luna／Flash。サイバー防衛は Daybreak を AWS 既存統制に載せる申請と 9/1 鍵。広告と Premium は「無料帯 UX」と「ヘビー席 SLA」を別 KPI に。CoT は暗号化思考の再使用禁止とログ監査。Manus 型巻き戻しはクロスボーダー契約の解除・データ削除 SLA をチェックリストに。Claude auto は分類器失敗モードを先に測る。Grok 4.6 は未着——4.5 と Grok Bot を別列で管理。見出しは Gemini 1B と Lightning と Daybreak AWS と Ads。現場は請求書とルーティング表と allowlist と鍵と削除カレンダーと差し替え手順。測れ。貼れ。天井はアプリ定義で数えろ。幻は幻のまま捨てろ。
